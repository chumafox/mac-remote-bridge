# mac-remote-bridge (Инструкция на русском)

**mac-remote-bridge** — это инструмент удалённого администрирования и помощи для macOS без необходимости настраивать роутеры, пробрасывать порты, белый IP или устанавливать сторонние громоздкие клиенты (TeamViewer, AnyDesk).

Работает через защищённый обратный TCP-туннель (Pinggy / SSH) по исходящему порту 443 — проходит сквозь любой NAT, мобильный интернет, отельные и корпоративные сети.

## 🚀 Быстрый старт (на удалённом Mac)

### Рекомендуемый запуск (с просмотром):
```bash
curl -fsSL https://raw.githubusercontent.com/chumafox/mac-remote-bridge/main/bridge.sh -o /tmp/bridge.sh
bash /tmp/bridge.sh
```

### В одну строку (через официальный GitHub):
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/chumafox/mac-remote-bridge/main/bridge.sh)" -- -y --vnc
```

### Через короткую ссылку:
```bash
bash -c "$(curl -fsSL https://clck.ru/3VCyvf)" -- -y --vnc
```

## ⚙️ Что делает скрипт при запуске:

1. **Включает Удалённый вход (SSH / Remote Login):** Если он был выключен (требуется разовый ввод пароля администратора).
2. **Включает Общий экран (Screen Sharing / VNC):** При передаче флага `--vnc`.
3. **Генерирует ключ туннеля:** Создаёт временный `id_tunnel` для надёжного рукопожатия с Pinggy даже на чистой macOS.
4. **Прописывает публичный SSH-ключ оператора:** Чтобы оператор входил без ввода пароля (при `revert` ключ автоматически удаляется).
5. **Поднимает обратный туннель:** Защищённый SSH на порт 443.
6. **Синхронизирует GitHub Gist:** Автоматически обновляет `session.json` и `connect.sh` с актуальными портами.
7. **Удерживает активность (`caffeinate`):** Предотвращает засыпание системы при бездействии.

## 👨‍💻 Подключение оператора

После того как клиент запустил скрипт, оператор может подключиться в один клик.

### 1. Подключение к консоли (SSH)

Прямая команда из Gist:
```bash
curl -fsSL https://gist.githubusercontent.com/chumafox/0660617e54c4556e9b31a48f8a48f787/raw/connect.sh | bash
```

Или по удобному алиасу в `~/.zshrc`:
```bash
remote-mac
```

### 2. Подключение к экрану (VNC / Графический рабочий стол)

Функция в `~/.zshrc`:
```bash
remote-screen
```
*Автоматически пробрасывает VNC-туннель на локальный порт 5901 и открывает стандартную утилиту «Общий экран» (Screen Sharing).*

## 🔄 Автономный режим (LaunchDaemon)

Если вам нужно, чтобы удалённый Mac был **доступен всегда** (даже после перезагрузки и без входа пользователя):

```bash
bash -c "$(curl -fsSL https://clck.ru/3VCyvf)" -- -y --vnc -d
```

* **Флаг `-d` / `--daemon`:** Регистрирует системный демон `/Library/LaunchDaemons/com.mac-remote-bridge.plist` (`RunAtLoad: true`, `KeepAlive: true`).
* **Автостарт:** Туннель поднимается в момент включения питания Mac.
* **Чистый откат:** Команда `bridge.sh revert` корректно выгружает и удаляет демон.

## 📋 Таблица параметров и флагов

| Флаг | Описание |
| --- | --- |
| `-y`, `--yes` | Пропустить диалог подтверждения |
| `-d`, `--daemon` | Установить постоянный системный LaunchDaemon (автозапуск при загрузке) |
| `--vnc` | Включить Screen Sharing (VNC) для графического доступа |
| `--no-vnc` | Отключить Screen Sharing (только консольный SSH) |
| `--key KEY` | Публичный SSH-ключ оператора для беспарольного входа |
| `--gist ID` | ID секретного GitHub Gist для авто-публикации сессии |
| `--gist-token T` | GitHub Personal Access Token |
| `--no-gist` | Отключить публикацию в Gist |
| `--force` | Принудительно перезапустить существующую сессию |
| `--foreground` | Держать туннель в текущем окне терминала |
| `--lang ru` / `en` | Принудительно задать язык интерфейса |

## 🛑 Остановка и полный откат

```bash
# Проверить статус активного туннеля
~/.mac-remote-bridge/bridge.sh status

# Остановить только туннель (SSH/VNC останутся включены)
~/.mac-remote-bridge/bridge.sh stop

# Полный откат (остановить туннель, выключить SSH/VNC/LaunchDaemon и удалить ключ оператора)
~/.mac-remote-bridge/bridge.sh revert
```

---

## 🛡️ Безопасность

* Вход защищён стандартным SSH-протоколом macOS (пароли и ключи проверяются локальным демоном `sshd`).
* VNC пробрасывается строго внутри зашифрованного SSH-соединения (отдельный публичный порт для VNC не открывается).
* Скрипт не оставляет скрытых процессов после выполнения команды `revert`.
